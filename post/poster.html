⚙ Core Advantages
  • ✓ Zero-Copy Parsing — std::span views into raw buffer, no string copies
  • ✓ O(1) Field Lookup — Direct array indexing by FIX tag number
  • ✓ SIMD Scanning — AVX2 delimiter detection, up to 14.7x on large buffers
  • ✓ Compile-Time Offsets — consteval field tables, zero runtime cost
  • ✓ No Heap Allocation — PMR arena pools + SessionHeap (mimalloc)
  • ✓ Cache-Line Aligned — alignas(64), branch hints, LTO
